<summary><span class="hz-item-title">Goose：基于栈内存模型的安全系统编程语言</span> <span class="hz-item-score">⭐️ 8.0/10</span></summary>

Goose 编程语言由其创建者（aardappel）推出，它是一种内存安全的系统级语言，采用基于栈的内存模型，无需堆分配器、垃圾回收器或生命周期标注。在其自身的基准测试中，它声称比 C++ 和 Rust 运行更快且内存占用更少。 如果性能和安全性声明成立，Goose 可能为系统编程提供一个比 Rust 复杂的借用检查器更简单的替代方案，从而吸引那些希望获得内存安全但又不想面对陡峭学习曲线的开发者。其新颖的内存管理方法可能会影响未来的语言设计，并为确定性、低延迟软件激发新思路。 Goose 使用固定数量的栈来管理动态大小的值，这引发了关于如何处理任意数据结构（如存储字符串的哈希表）的问题。该语言的 README 并未明确说明未定义行为（UB），使其安全保证相比 Rust 不够清晰。

**背景**: 像 C 和 C++ 这样的系统编程语言提供手动内存管理，但容易出现缓冲区溢出和释放后使用等错误。Rust 引入了编译时所有权和借用检查，以在没有垃圾回收器的情况下确保内存安全，但其复杂性常被诟病。Goose 旨在通过使用栈进行所有内存分配来简化这一点，从而避免堆和复杂的生命周期分析。
