<summary><span class="hz-item-title">Outlook.com 拒绝接收未配置 DMARC 的域名邮件</span> <span class="hz-item-score">⭐️ 7.0/10</span></summary>

据报道，Outlook.com 已开始拒绝接收来自未发布 DMARC 记录的域名的邮件，并返回永久性的 5xx 投递失败错误。微软并未正式宣布这一变化，但邮件服务器管理员已观察到该现象并在网上引发广泛讨论。 这一举措促使域名所有者采用 DMARC 这一关键邮件认证标准，并可能对尚未实施该标准的组织的邮件送达率产生重大影响。同时，它也凸显了微软等大型邮箱提供商在设定事实上的邮件标准方面日益增强的影响力。 这些拒绝似乎是永久性的 5xx 错误，意味着未配置 DMARC 的合法发件人的邮件会被退回，而不是被静默过滤。然而，一些管理员报告称，即使正确配置了 SPF、DKIM 和 DMARC，Outlook.com 也会静默丢弃来自某些 IP 的邮件，这引发了对过滤机制不透明的担忧。

🔗 [来源](https://mailroute.net/blog/outlook-rejecting-email-without-dmarc)

hackernews · xmddmx · 11月8日 19:20 · [社区讨论](https://news.ycombinator.com/item?id=50416158)

**背景**: DMARC（基于域的消息认证、报告和一致性）是一种建立在 SPF 和 DKIM 之上的邮件认证协议，用于防止域名欺骗。它允许域名所有者发布策略，告知接收服务器如何处理未通过认证的邮件，例如拒绝或隔离。主要邮件提供商越来越多地强制执行 DMARC 以打击垃圾邮件和网络钓鱼，但强制执行可能会无意中阻止尚未采用该标准的合法发件人。

一个名为 llama-modchip 的 GitHub 项目展示了如何在仅有 64GB 内存且无 GPU 的机器上运行 284B 参数的 DeepSeek 模型（很可能是 DeepSeek-V4-Flash，一种总参数 284B、每 token 仅激活 13B 的混合专家模型）。该仓库提供了一个修改版的 llama.cpp 构建，通过激进的量化和共享内存控制结构实现了这一目标。 该项目突破了消费级硬件的极限，表明大型 MoE 模型无需昂贵 GPU 即可在本地运行。它可能让预算有限的用户也能使用强大的 AI 模型，并激发本地推理社区的进一步优化。 该方法依赖于重度量化（可能是 4 位或更低）以及一个自定义的共享内存控制机制，该机制在 ggml-cpu/ops.cpp 的每次前向传播中读取一个 48 字节的 POSIX 结构体。然而，社区成员指出，低于 4 位的量化通常会导致性能显著下降，而且该仓库相对于普通 llama.cpp 的实际优势仍不明确。

<summary><span class="hz-item-title">Claude Code“不再询问”功能导致 1,122 个公开 GitHub 文件泄露密钥</span> <span class="hz-item-score">⭐️ 7.0/10</span></summary>

一项安全分析发现，Claude Code 的“不再询问”选项会将批准的 shell 命令写入.claude/settings.local.json 文件，当开发者手动将此文件提交到公开 GitHub 仓库时，其中嵌入的密码或 API 密钥便会暴露；研究人员识别出 1,122 个包含密钥的此类文件。 这凸显了 AI 编码代理中真实存在的密钥管理风险，这些代理越来越多地运行 shell 命令并在本地存储权限决策；开发者和安全团队需要将代理配置文件视为敏感信息，并确保它们被 gitignore 忽略。 泄露需要两个条件：用户必须手动提交.claude/settings.local.json 文件（Claude Code 在创建该文件时会自动将其加入 gitignore），且批准的命令必须包含明文密钥；Claude Code 团队表示正在研究密钥清理功能，但指出该文件本应保持在本地。

🔗 [来源](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again)

hackernews · shmulc · 11月7日 20:45 · [社区讨论](https://news.ycombinator.com/item?id=50407882)

**背景**: Claude Code 是 Anthropic 的 AI 编码代理，可以在开发者机器上执行 shell 命令。默认情况下，它在运行命令前会请求许可，选择“是，并且不再询问”会将允许规则保存在项目内的.claude/settings.local.json 中。该文件用于个人、机器本地设置，不应提交到版本控制，但一些用户手动创建并提交了它，有时命令中还嵌入了密钥。
