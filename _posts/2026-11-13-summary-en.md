Rust 1.100.0 was released on November 12, 2026, stabilizing the never type (!), custom allocators, and introducing Cargo dependency cooldowns (minimum publish age) via RFC 3923. The release also makes cargo-install use the existing lockfile by default and adds warnings for unused dependencies. This is a monumental release that resolves long-awaited features: the never type improves type inference and control flow, custom allocators enable performance-critical and embedded use cases, and dependency cooldowns enhance supply-chain security by letting teams delay adopting newly published crates. These changes affect all Rust developers and signal the language's continued maturation. The never type stabilization unifies type-inference fallback to ! across editions and turns std::convert::Infallible into an alias for !. Dependency cooldowns are opt-in and only apply to registry dependencies, not git or local path dependencies, and cargo install now uses the lockfile by default, making --locked a no-op.

Custom allocators let developers replace the global memory allocator for specific data structures or entire programs, which is crucial for embedded systems and high-performance applications. Cargo, Rust's package manager, now supports dependency cooldowns to mitigate supply-chain attacks by ignoring very recently published crate versions.
