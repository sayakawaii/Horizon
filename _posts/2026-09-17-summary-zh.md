<summary><span class="hz-item-title">Hister：为你的浏览历史与本地文件打造的私有搜索引擎</span> <span class="hz-item-score">⭐️ 8.0/10</span></summary>

Hister 是由注重隐私的元搜索引擎 Searx 的原作者 asciimoo 打造的一款全新开源、可自托管的个人搜索引擎。它会从你访问过的网页、书签、浏览器历史、本地文件以及抓取的网站中构建私有的全文索引，并保存提取出的内容与离线结果预览，因此即使原始来源不可用，信息依然可以被搜索到。 这一点很重要，因为它重新带回了 Google Chrome 从 2008 年到 2013 年左右提供的功能——对所有访问过的页面进行离线全文搜索——许多用户至今仍怀念这一功能。它也反映出一种更广泛的趋势：人们越来越倾向于使用保护隐私、可自托管的工具，从而掌控自己的数据，而不是依赖云服务。 Hister 目前版本为 v0.18.0，可通过网页界面、终端、CLI 和 HTTP API 访问，且不强制依赖云服务，也没有遥测。它运行在你自己的机器或服务器上；作者表示，由于 Searx 背后的元搜索概念存在局限，他为 Hister 选择了不同的、基于索引的方案。
