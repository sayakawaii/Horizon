Farid Zakaria launched trynix.dev, which uses qemu-wasm to run an x86_64 Linux virtual machine entirely inside a browser via WebAssembly, capable of booting any Nix package from the past 13 years. Packages are URL-addressable, so visiting a link like https://trynix.dev/?pkg=python3%403.6.2 and clicking "Load" opens an interactive shell running Python 3.6.2 from 2017. This makes historical and reproducible software instantly accessible without installation, lowering the barrier for software archaeology, debugging old environments, and reviewing pull requests. The VM is powered by ktock/qemu-wasm, which combines QEMU's TCI interpreter with TCG so that frequently executed translation blocks are compiled to WebAssembly for speed. Farid also built trynix-preview, a GitHub Action that comments a link on a pull request so reviewers can boot the PR's build directly in the browser with no server involved.

rss · Simon Willison · Sep 10, 23:44

**Background**: Nix is a purely functional package manager that stores every package in an immutable path containing a hash of all its inputs, which guarantees reproducible builds and allows multiple versions to coexist. qemu-wasm is a project that compiles the QEMU emulator to WebAssembly, enabling full-system emulation inside a browser tab. trynix.dev combines these ideas with the nixpkgs-multiverse index to boot any package nixpkgs ever shipped.
