中国 AI 实验室 Z.ai 发布了 GLM-5.4，这是其首个采用循环 Transformer 架构的模型，其中一组权重共享层会运行多次迭代，从而在不增加参数量的情况下加深网络。这是一周内第二个公布的循环 Transformer，此前 Thinking Machines Lab 于 11 月 20 日发布了 Inkling 2 Mini。 两家独立实验室在几天内先后采用循环 Transformer，表明该架构可能正成为单纯堆叠深度的实用替代方案，有望以更少的 token 提升智能体编程等重推理任务的表现。若这一趋势延续，可能重塑前沿模型在参数量、算力与推理成本之间的权衡方式。 据报道 GLM-5.4 是一个 750B 模型，其循环 Transformer 让 28 个权重共享层运行 2 次迭代，Z.ai 为此做了三项改动以在该规模下保持实用；该模型尚未开放权重，目前需订阅 Coding Plan 才能使用，不过其位于 https://api.z.ai/api/v1 的 OpenAI 兼容 Responses API 也可用普通 API 密钥访问。

**背景**: 标准 Transformer 在前向传播中每层只运行一次，因此要让模型更深通常意味着增加参数量。循环 Transformer（也称循环深度或循环深度共享）则对同一隐藏表示反复应用同一组层，通过复用权重以更低的参数成本获得有效深度。跨层权重共享是已有思路，ALBERT 便是代表，而循环设计近来因 Nanbeige 4.2 等模型以及关于 OpenAI Astra 的报道而受到关注。
