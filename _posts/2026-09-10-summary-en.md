<summary><span class="hz-item-title">Forgejo 16.0.3 and Earlier Hit by Critical RCE via Template Expansion</span> <span class="hz-item-score">⭐️ 8.0/10</span></summary>

Forgejo versions up to and including 16.0.3 contain a critical remote code execution vulnerability tied to template expansion during git repository initialization, fixed in the 16.0.4 release. When a new repository is generated from a template repository, Forgejo clones the template, removes the .git folder, performs variable template expansion on files listed in .forgejo/template, and then initializes a fresh git repository — a process that could be abused to read arbitrary files and execute arbitrary processes on the host. Forgejo is a widely used self-hosted Git forge, so a critical RCE lets remote authenticated attackers compromise the servers of organizations and individuals who host their own instances. The flaw also highlights the security risks of template-based repository generation, a feature common to many forge platforms. The vulnerability stems from directory traversal in Forgejo's repository-template processing, allowing arbitrary files on the filesystem to be processed during template expansion. The fix, tracked as CVE-2025-68937, adds a check after variable expansion is completed to prevent the issue.
