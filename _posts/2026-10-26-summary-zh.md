<summary><span class="hz-item-title">微软提出 Type Server Protocol，标准化 Python 类型检查器集成</span> <span class="hz-item-score">⭐️ 7.0/10</span></summary>

微软发布了 Type Server Protocol (TSP)，这是一个基于 JSON-RPC 的协议，允许任何编辑器或工具将 Python 类型检查器集成为一等后端。TSP 扩展了 Language Server Protocol (LSP)，文档位于 pylance-release 仓库中。 TSP 旨在标准化 Pyright、Pyrefly 和 Ty 等类型检查器与编辑器的通信方式，有望减少碎片化，并在不同 IDE 中实现一致的类型分析。这可以简化 Python 开发者的工具链，并促进高级类型检查的更广泛采用。 TSP 目前针对 Python，但未来可能通用化；它定义了协议版本、快照、搜索路径、导入解析以及计算/声明/预期类型的请求。该协议采用 MIT 许可证，已得到 Astral 的 Ty 等工具的支持，而 basedpyright 等则提出了批评。

🔗 [来源](https://github.com/microsoft/pylance-release/blob/main/docs/tsp/type-server-protocol.md)

hackernews · adamnemecek · 10月26日 18:14 · [社区讨论](https://news.ycombinator.com/item?id=50248371)

**背景**: Language Server Protocol (LSP)标准化了编辑器和语言服务器之间的通信，提供自动补全和诊断等功能。然而，LSP 可能无法完全满足类型检查器的特定需求，因为类型检查需要更深入的类型分析。TSP 基于 LSP 构建，为类型服务器提供专用协议，类型服务器维护工作区的类型分析状态并回答类型查询。
