Hugging Face 与 NVIDIA 联合发布了一篇教程，介绍如何使用 NVIDIA Warp 和 MjWarp（MuJoCo Warp）来加速机器人仿真与学习工作流。该指南向开发者展示了如何将基于 Python 的 GPU 仿真框架 Warp 与 GPU 优化的 MuJoCo Warp 物理后端结合使用。 GPU 加速仿真正成为机器人与强化学习研究的瓶颈突破口，因为这类训练往往需要数百万次物理步进。该教程降低了 AI/ML 研究者采用并行仿真工具的门槛，有望显著加快机器人学习实验的速度。 Warp 是一个用于 GPU 加速仿真、机器人和机器学习的 Python 框架，要求 Python 3.10 或更高版本，并为 Windows、Linux 和 macOS（Apple Silicon）提供 wheel 包。MjWarp 是基于 Warp 重新实现的 MuJoCo，针对吞吐量（单位时间内的总仿真步数）而非延迟进行优化，快速仿真需要 NVIDIA GPU，但仍支持 CPU 用于开发和调试。

🔗 [来源](https://huggingface.co/blog/nvidia/how-to-use-nvidia-warp-and-mjwarp)

rss · Hugging Face Blog · 9月23日 18:41

**背景**: MuJoCo 是机器人和强化学习领域广泛使用的物理仿真器，传统上针对低延迟的单步仿真进行优化。由 Google DeepMind 开发的 MuJoCo Warp（MjWarp）用 Warp 重新实现了 MuJoCo 的核心算法，从而能在 NVIDIA GPU 上并行运行大量仿真。NVIDIA Warp 本身是一个 Python 框架，允许开发者编写可编译为高效 GPU 内核的仿真与空间计算代码。二者结合可实现大规模并行机器人训练，MjWarp 也是 Isaac Lab 中 Newton 后端的主要经过验证的求解器。
