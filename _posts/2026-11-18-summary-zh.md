<summary><span class="hz-item-title">Java4Shell：OpenJDK Base64 解码器中的严重 RCE 漏洞</span> <span class="hz-item-score">⭐️ 9.0/10</span></summary>

Calif.io 披露了 CVE-2026-114938，代号“Java4Shell”，这是 OpenJDK 优化的 AVX-512 Base64 解码汇编代码中的一个远程代码执行漏洞，允许未经身份验证的攻击者触发堆内存损坏。该漏洞的 CVSSv4.0 评分为 9.2，影响 Java 17（OpenJDK 和 Oracle Java SE 17.0.6 及后续更新）。 OpenJDK 是支撑无数企业应用的 ubiquitous 运行时，因此 Base64 解码这类核心工具中的远程可利用内存损坏漏洞使大量面向互联网的服务面临风险。尽管可靠的 RCE 需要针对特定环境进行利用工作，但拒绝服务和定向攻击的可能性仍然很大。 该漏洞仅存在于基于 HotSpot 的 JVM（OpenJDK、Oracle JDK、GraalVM）中，这些 JVM 会生成存在漏洞的 AVX-512 存根；OpenJ9 和 GCJ 不受影响，而 Azul Prime（Zing）替换了 C2，因此可能不受影响。利用过程对 RTT 和抖动等网络条件敏感，可靠的代码执行需要通过网络安全地进行堆布局，而拒绝服务则更容易实现。
